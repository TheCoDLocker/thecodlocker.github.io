Why there are only three builds

The league plays on a published ruleset that bans whole attachment categories, and teams add a further layer of gentlemen’s agreements — GAs — restrictions everyone honours that were never written into the game. Optics, lasers and magazines are gone before a player makes a single choice. What is left is a handful of slots, and the league has landed on the same answers in nearly all of them.

The AR builds differ by one slot

Both MOD 15 builds run the Lethal Tools Sight, Recoil Springs, the Peregrine Grip and the Wanderer Stock. The fifth slot is the only difference: Build 1 takes the Quickstep Foregrip, Build 2 takes the Fusion Barrel. Those are different attachment categories rather than two versions of the same part, so it is a real choice and not a preference between near-identical options.

Build 1 is run by Huke, HyDra and Cellium. Build 2 by Dashy, Scrap and RenKoR. Three and three, across four organisations. There is no consensus pick between them.

The SMG has one build

Once the GAs are applied there is a single viable MPC configuration and the whole league runs it: Recoil Springs, the 13.1″ Razorback Barrel, the Zeroshift Underbarrel, the Photonic Grip and the K-1 Pedal Stock. No decision, nothing to compare.

Which is the argument for paying more attention to settings than loadouts. The six AR players above run the same gun with one slot between them, and their sensitivities still range from 1.65 to 2.1 with field of view from 98 to 102. That spread is where the real differences sit, and the league stats page breaks it down across all 51 players.

Using the build codes

Each build carries its in-game code. Entering it in the gunsmith rebuilds the class exactly, which matters most for parts with near-identical names where picking the wrong variant is easy. Codes are tied to a game version, so one that stops resolving usually means an update moved the underlying attachment IDs rather than that you typed it wrong.

A build is tuned around the sensitivity and deadzones of the player running it, so it is worth opening their settings page alongside the code rather than dropping the class onto your own.
